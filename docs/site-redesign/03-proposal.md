## 1. Ամփոփում

1. **Ուղղությունը.** upandup.am-ի «ճարտարապետական» զսպվածությունը (շրջանակներ, կարճ գիծ վերնագրի տակ, մեծ գունատ բառեր, շատ օդ, սուր անկյուններ) տեղափոխում ենք **բաց թղթային ֆոնի + գծագրի ցանցի + մեկ ոսկեգույն ակցենտի** վրա, այսինքն՝ GARON-ի լոգոյի և Instagram-ի արդեն հաստատված ոճի վրա։
2. **Ինչու բաց և ոչ սև.** սեփականատերը հաստատել է բաց/blueprint ոճը (L02 v4) և չի ուզում մուգ ֆոն. ներկայիս մութ կայքը «չի շնչում» (աուդիտ), իսկ ռեֆերենսի պրեմիում զգացողությունը գալիս է ձևից ու լուսանկարներից, ոչ թե սև գույնից։
3. **Ինչու է սա վաճառքի, ոչ միայն գեղեցկության հարց.** կայքում չկա հեռախոս, ձևը `mailto:` է, `/projects`-ի քարտերը տանում են 404. դիզայնից առաջ պետք է շտկել կապի ուղին (Փուլ 0)։
4. **Ինչը չենք պատճենում.** 183 ՄԲ էջ, մեկ երկար էջ առանց մենյուի, CTA-ների ու վստահության տարրերի բացակայություն, անհայերեն տառատեսակ։
5. **Գլխավոր խոստումը կայքում** (strategy, դիրքավորում Ա)՝ «գինը նախապես, ընթացքը՝ տեսանելի». բայց միայն այն պայմանները, որոնք սեփականատերը **գրավոր կհաստատի**. ոչ մի չստուգված թիվ, stock նկարը երբեք չի ներկայացվում որպես GARON-ի աշխատանք։

## 2. Դիզայնի ուղղություն

### 2.1 Պալիտրա

Հիմքը՝ բաց, ակցենտը՝ մեկ (ոսկի), գույնը թողնում ենք լուսանկարներին (ջրի կապույտը, կանաչը՝ լուսանկարից, ոչ թե UI-ից)։

### 2.2 Տառատեսակներ (ստուգված)

Ստուգվել է Next.js-ի ներկառուցված Google Fonts տվյալների բազայով (`node_modules/next/.../font-data.json`)։ **Հայերեն subset ունեն միայն 3 ընտանիք՝ Noto Sans Armenian, Noto Serif Armenian և Handjet** (Handjet-ը դեկորատիվ «պիքսելային» է, մեզ չի համապատասխանում)։ **Montserrat-ը և Cormorant Garamond-ը հայերեն չունեն** (այժմ էլ հայերենը ցուցադրվում է Noto-ով)։ «Montserrat Armenian», «Mardoto», «Arian AMU» Google Fonts-ում չկան։

**Առաջարկ՝ մեկ ընտանիք, երեք գիր.**
- **Noto Sans Armenian** (hy) + **Noto Sans** (en/ru, ունի cyrillic)՝ նույն դիզայներական ընտանիքը, նույն մետրիկան. ռուսերեն, անգլերեն և հայերեն էջերը նույն տեսքն ունեն։ Երկուսն էլ variable են՝ `wght 100–900` և `wdth 62.5–100` առանցքով։
- Վերնագրեր՝ 600, `wdth 87.5` (semi-condensed)՝ երկար հայերեն բառերը մոբայլում չեն կտրվում (ռեֆերենսի «…ԾԱՌԱՅՈՒԹՅՈՒՆՆԵ» սխալը)։
- Ֆոնային մեծ բառեր՝ 800, `wdth 62.5–75`, մեծատառ։
- Սերիֆը (Cormorant + Noto Serif Armenian) **հանում ենք**. աուդիտը ճիշտ է նկատել, որ դրանք տարբեր բնավորություն ունեն, իսկ լոգոյի «GARON»-ը sans է։ Արդյունքում՝ 4 font family-ի փոխարեն 2 (ավելի քիչ բեռ)։

|---|---|---|
| H1 | `clamp(2.25rem, 5.5vw, 4.5rem)`, 600, line-height 1.05 | Ոչ տառ առ տառ «G A R O N» span-եր. H1-ում բանալի բառեր |

### 2.3 Ցանց և տարածություններ

- Բովանդակության լայնություն՝ **1200px** (max), 12 սյուն, gutter 24px; կողային padding `clamp(20px, 6vw, 96px)`։
- Ուղղահայաց ռիթմ՝ 8px քայլ. բաժնի padding **120px desktop / 72px mobile**, բաժնի ներսում՝ 48/32px։
- Layout-ների «գրադարան» (աուդիտի «ամեն տեղ twoCol» խնդրի դեմ). (ա) full-bleed լուսանկար, (բ) zigzag ֆոտո + offset քարտ, (գ) 3-սյուն քարտեր, (դ) թվերի շերտ, (ե) թայմլայն, (զ) accordion (FAQ), (է) before/after slider։ Կանոն՝ **նույն layout-ը 2 անգամ անընդմեջ չի կրկնվում**, zigzag՝ ≤ 3 բլոկ մեկ էջում (ռեֆերենսի ~20 բլոկը ձանձրալի է)։

### 2.4 Ստորագրային տարրեր (ռեֆերենսից ոգեշնչված, բայց մերը)

1. **Վերնագրի տակ կարճ գիծ**՝ 48×3px `--gold-dark` (ռեֆերենսում՝ սև 50×3)։ Միակ տեղը, որտեղ ոսկին հայտնվում է ամեն բաժնում։
2. **Offset շրջանակ**՝ 1px `--ink` եզր, որը 16px տեղաշարժված է լուսանկարից կամ սպիտակ քարտից (ներքև-աջ)։ Ռեֆերենսի 15px հաստ սևի փոխարեն՝ բարակ «գծագրային» գիծ. ավելի թեթև, ավելի «ինժեներական»։ Օգտագործել՝ about-ի դիմանկար, հաշվիչի արդյունքի քարտ, կապի ձև, նախագծի գլխավոր կադր։
3. **Մեծ գունատ ֆոնային բառեր**՝ «ԼՈՂԱՎԱԶԱՆ», «ՏՈՒՆ», «ՎԵՐԱՆՈՐՈԳՈՒՄ», «ԳՈՐԾԸՆԹԱՑ» (en՝ POOLS…, ru՝ БАССЕЙНЫ…)՝ ըստ լեզվի, `clamp(5rem, 14vw, 12rem)`, 5% թափանցիկ, `aria-hidden="true"`, բաժնի վերին ձախ անկյունից «դուրս ընկած»։ Մեկ էջում ≤ 3 հատ։
4. **Գծագրի ցանց**՝ CSS `background-image` (2 linear-gradient), 32px քայլ, `--line` 40%. ոչ թե PNG։ Հիմնական hero-ում և «Գործընթաց» բաժնում (Instagram-ի ոճը)։
5. **Լոգոյի գծային մոտիվ**՝ լոգոյի սյուներ/տանիքի ուրվագծից (SVG `garon-mark-*.svg`) 1px գծանկար. օգտագործել որպես բաժանարար և նկարների «տանիքաձև դիմակ» (owner-preferences-ում արդեն հաստատված է)։
6. **Պիտակ նկարի վերևի աջ անկյունում**՝ փոքր սպիտակ արկղ «Լողավազան · Կոտայք · 2025» (Instagram-ի «փոքր պիտակների» նույն լեզուն). տվյալները՝ միայն ստուգված։
7. **Անկյուններ՝ 0px, ստվերներ՝ ոչ** (ռեֆերենսից)։ Խորությունը՝ միայն paper/white/stone շերտերով և offset շրջանակով։

### 2.5 Շարժում (զուսպ)

- **Լոգոյի ինտրո**՝ պահում ենք (սեփականատերը սիրում է), բայց. միայն առաջին այցին մեկ session-ում, **≤ 1.2 վ**, SVG/CSS (սյուներ → տանիք → ոսկե մասը «նստում է»), **առանց 00→100% հաշվիչի** և առանց բովանդակությունը փակելու (hero-ն ներքևում արդեն ռենդեր է → LCP-ը չի տուժում), կոճակ/սեղմում՝ բաց թողնել։
- Reveal՝ fade + 16px slide-up, 400–500ms, `ease-out`, ամեն տարր մեկ անգամ։
- Hover՝ նկարի scale 1.03 (600ms), կոճակի ոսկե գծի ընդլայնում։ Ոչ «պարող» էֆեկտներ, ոչ parallax մոբայլում։
- Scroll-ով կառավարվող վիդեոն (ScrollVideo) **հանում ենք**. փոխարենը՝ poster + լուռ loop ≤ 1.5 ՄԲ միայն desktop-ում, մոբայլում՝ միայն poster։
- `prefers-reduced-motion`՝ ամեն ինչ անջատված (արդեն կա, պահել)։

### 2.6 Լուսանկարների կանոններ

1. **Միայն GARON-ի իրական աշխատանք** այն տեղերում, որտեղ խոսքը մեր աշխատանքի մասին է։ Stock-ը (`public/stock/*`)՝ հեռացնել ամբողջությամբ։ Եթե ինչ-որ տեղ անհրաժեշտ է «մթնոլորտային» նկար, այն պետք է լինի աբստրակտ (նյութ, գծագիր) և **երբեք** չնմանվի «մեր աշխատանքին»։
2. Phone կադրերը՝ միայն `enhanced/` տարբերակով (`marketing/instagram/tools/enhance_photos.py`), փայտե տունը՝ բնօրինակով (owner-decisions 2026-11-11)։
3. Մեկ գունամշակում բոլոր կադրերի համար. տաք-չեզոք white balance, ուղիղ ուղղահայացներ, առանց աղբի/բրեզենտի կադրի առաջին պլանում (կտրել)։
4. Յուրաքանչյուր նախագիծ՝ **«Սկիզբ → Ընթացք → Արդյունք»** եռյակ (սեփականատիրոջ սիրելի ձևաչափը) + 1 «հերոս» կադր 3:2 և 1 ուղղահայաց 4:5։
5. Տեխնիկա՝ `next/image`, AVIF/WebP, `srcset` 480/828/1200/1920, hero-ն `priority`, մնացածը lazy. **էջ ≤ 1.5 ՄԲ մոբայլում, LCP < 2.5 վ**։
6. Մարդիկ կադրում՝ թույլատրված (աշխատողների դեմքերը չմշուշել՝ owner-decisions 2026-11-10)։
7. Միջնաժամկետ՝ **մեկ պրոֆեսիոնալ ֆոտոշարք** (ռեֆերենսի որակի 70%-ը սա է). տես 4-րդ բաժին, «Should»։

### 3.1 Sitemap

Հայերենը՝ `/`-ից, մյուսները՝ նախածանցով (պահում ենք ներկայիս բոլոր URL-ները, որ ինդեքսը չկորչի).

### 3.3 Մոբայլ

- **Ներքևի sticky գոտի** (56px, միշտ տեսանելի, բացի ձևի դաշտը ֆոկուսում լինելուց). **Զանգել** (`tel:`) · **WhatsApp** (`https://wa.me/374…?text=Բարև, հետաքրքրված եմ…`) · **Viber** (`viber://chat?number=%2B374…`) · **Հաշվարկ**։ Սա այն է, ինչ չունի ոչ ռեֆերենսը, ոչ մենք (աուդիտ. «մոբայլում header CTA-ն թաքնված է»)։
- Header՝ 56px, լոգո + hamburger. մենյուն՝ լրիվ էկրան, ներքևում հեռախոս և լեզուներ։
- Hero՝ կադրը վերևում (4:5), տեքստը ներքևում (ոչ թե տեքստ նկարի վրա. կոնտրաստի խնդիր չի լինի)։
- Ֆոնային բառերը մոբայլում՝ `14vw`, առավելագույնը 1 էկրանում։ Zigzag-ը՝ մեկ սյուն, նկարը միշտ վերևում։
- Էջի երկարություն գլխավորում՝ նպատակ **≤ 9 էկրան** (այժմ մինչև 7000px ծառայության էջերում՝ ScrollVideo-ի spacer-ի պատճառով)։

## 4. Ինչ ավելացնել

**Ազնիվ պնդումների կանոն (բոլոր կետերի համար).** կայքում հրապարակվում է միայն այն, ինչ (1) սեփականատերը գրավոր հաստատել է և (2) կարելի է ապացուցել հաճախորդին պահանջի դեպքում (նախագիծ, փաստաթուղթ, պայմանագրի կետ)։ Չկա տվյալ → բաժինը թաքնված է (ինչպես հիմա `siteConfig`-ի դատարկ դաշտերը), ոչ թե լրացված «մոտավոր» թվով։ Stock նկար՝ երբեք որպես GARON-ի աշխատանք։ Կարծիք՝ միայն իրական մարդուց, նրա համաձայնությամբ։ «25+ տարի / 50+ տուն» տիպի թվեր՝ ոչ (risks R02)։

## 5. Ինչ ՉԵՆՔ վերցնում ռեֆերենսից

1. **Սև/մոնոխրոմ հիմքը** որպես ամբողջություն. վերցնում ենք զսպվածությունը, ոչ թե սևը (սեփականատիրոջ նախապատվությունը՝ բաց ֆոն)։ Սև՝ միայն footer և առավելագույնը 1 բաժին։
2. **Մեկ էջ առանց մենյուի** (~21 000px մոբայլում)՝ ոչ. բազմաէջ կառուցվածք, sticky header մենյուով, ամեն ծառայություն՝ իր URL-ով (SEO)։
3. **183 ՄԲ էջ, 5472px նկարներ, lazy-load-ի բացակայություն**՝ ոչ. սահման ≤ 1.5 ՄԲ մոբայլում։
4. **Revolution Slider-ի hero** (փոփոխվող սլայդներ, սպիտակ դատարկ ուղղանկյուններ բեռնման ժամանակ)՝ ոչ. մեկ ստատիկ կադր։
5. **Poppins + fallback հայերեն, 12px body, երկար հայերեն UPPERCASE վերնագրեր**՝ ոչ։
6. **CTA-ների, հեռախոսի, WhatsApp/Viber-ի, քարտեզի, կարծիքների բացակայություն**՝ ոչ. սրանք մեր Must-ն են։
7. **Ձև առանց հեռախոսի դաշտի, label-ների և հաջողության վիճակի**՝ ոչ։
8. **~20 նույնատիպ zigzag բլոկ**, չոճավորված modal-ներ (ծառայությունները modal-ում թաքցնելը SEO-ի համար վատ է)՝ ոչ։
9. **SEO զրո** (կրկնակի title, H1 չկա, `lang="en"`, կոտրված sitemap)՝ ոչ. պահում ենք մեր ներկայիս 100/100 SEO բազան և ավելացնում hreflang։
10. **Գրաֆիկական տեքստ նկարի մեջ** (հատակագծերը)՝ ոչ. տեքստը միշտ HTML-ում։
11. **Կետավոր PNG pattern**՝ փոխարինում ենք CSS գծագրի ցանցով (մերը, Instagram-ի ոճից)։
12. **Ուղղահայաց պտտված պիտակներ** (rotate −90°)՝ հայերեն երկար բառերով անընթեռնելի են. չենք օգտագործում։

## 7. Հարցեր սեփականատիրոջը

1. **Որ հեռախոսահամարն** դնենք կայքում, և այն միացվա՞ծ է WhatsApp-ին ու Viber-ին։ Ո՞րն են աշխատանքային ժամերը, և ո՞ւմ Telegram-ին ուղարկենք կայքի հայտերը։
2. **Ունե՞ք գրասենյակի հասցե**, որը կարելի է ցույց տալ քարտեզում և Google Maps-ում, թե գրենք «Երևան և մարզեր»՝ առանց հասցեի։
3. **Նախագծերի փաստեր.** կարո՞ղ ենք pool-01, pool-02, pool-05, house-01-ի համար գրել համայնքը, չափերը/մ², տևողությունը և տարին (այժմ թույլատրված է միայն «մեր թիմի աշխատանքից»՝ առանց տարեթվի և հասցեի)։
4. **Ի՞նչ պայմաններ եք պատրաստ գրավոր խոստանալ կայքում**՝ երաշխիքի տարիներ (ըստ տների/լողավազանների/վերանորոգման), առավելագույն կանխավճար, չափագրման ժամկետ, շաբաթական ֆոտոհաշվետվություն։ Հաշվիչի գները (250/350/480 հազ. ֏/մ² և այլն) հաստատո՞ւմ եք, ԱԱՀ-ն ներառվա՞ծ է։
5. **Ֆոտոշարք.** համաձա՞յն եք 1 օրվա պրոֆեսիոնալ նկարահանման (≈150–300 հազ. ֏, գնահատական), և ո՞ր օբյեկտներն են հասանելի նկարելու համար։ Մինչ այդ գլխավոր hero-ում թողնե՞նք house-01-ի գիշերային կադրը (դուք այն հաստատել եք), թե՞ ընտրենք ցերեկային լողավազանի կադր։
6. **Հասարակական կառույցներ.** համաձա՞յն եք, որ այս ուղղությունը, մինչև առաջին նախագիծը/լիցենզիան, մնա միայն ծառայությունների ցուցակում և չլինի գլխավոր էջի ու մենյուի հիմնական առաջարկում։

## 8. Քննարկում. համաձայնություններ և առարկություններ

### Վերլուծաբան 1 (`01-reference-upandup.md`)

- **Համաձայն եմ**, որ պրեմիումը գալիս է ձևից (0px անկյուններ, առանց ստվերի, կարճ գիծ, offset շրջանակ, ֆոնային բառեր, օդ) և **միասնական ֆոտոշարքից**, ոչ թե տեխնոլոգիայից. նաև՝ սլայդեր ոչ, zigzag ≤ 3–5, body 16–18px, բազմաէջ, sticky CTA, արագությունը՝ պարտադիր։
- **Համաձայն չեմ** «սև `#0A0A0A` / սպիտակ / մոխրագույն» հիմքի և «ջրային կապույտ կամ օխրա» ակցենտի հետ։ GARON-ն արդեն ունի բրենդային ոսկի (լոգո) և սեփականատիրոջ հաստատած բաց/blueprint ոճ. երկրորդ ակցենտը կթուլացնի բրենդը, իսկ սև բաժինները հակասում են owner-preferences-ի «մուգ ֆոն՝ ոչ»-ին։ Կապույտը թող գա լողավազանի լուսանկարից։
- **Համաձայն չեմ** «counter-ներ՝ կառուցված օբյեկտներ, մ², տարիներ» առաջարկի հետ **հիմա**. GARON-ը սկսում է զրոյից (risks), իսկ նման թվերն արդեն մեկ անգամ հանվել են որպես չստուգված (commit 2945f12, risks R02)։ Թվերի շերտը կօգտագործենք **պայմանների** համար (երաշխիքի տարիներ, կանխավճար ≤ X%)՝ հաստատումից հետո։
- **Ճշգրտում** տառատեսակների մասին. «Montserrat Armenian», «Mardoto», «Arian AMU» Google Fonts-ում չկան, իսկ Google Fonts-ի Montserrat-ը հայերեն չունի։ Ստուգված տարբերակը՝ Noto Sans Armenian + Noto Sans։
- **Ճշգրտում** ֆոնային բառերի մասին. ոչ թե «POOLS/HOUSES», այլ ըստ էջի լեզվի («ԼՈՂԱՎԱԶԱՆ» hy էջում)։

### Վերլուծաբան 2 (`02-garon-audit.md`)

- **Լիովին համաձայն եմ** Փուլ 0-ի հետ (404, mailto, հեռախոս, splash, mp4, stock, analytics) և լեզուների URL-ների, պորտֆոլիոյի փաստերի, «ապացույց-կենտրոն» գլխավոր էջի հետ։ Իմ 3.2-ը հիմնականում նրա «Մեծ փոփոխություններ #1»-ն է՝ ռեֆերենսի վիզուալ լեզվով։
- **Մասամբ համաձայն չեմ** «paper/stone + ոսկի + ջրի կապույտ ակցենտ» պալիտրայի հետ. paper/stone + ոսկի՝ այո, կապույտ՝ ոչ (նույն պատճառով, ինչ վերևում)։
- **Մասամբ համաձայն չեմ** splash-ի մասին. աուդիտը թույլ է տալիս «հեռացում կամ CSS intro». ես առաջարկում եմ **պահել** լոգոյի կառուցման ինտրոն (սեփականատերը այն հատուկ նշել է որպես սիրելի), բայց ≤ 1.2 վ, 1 անգամ session-ում, առանց հաշվիչի և առանց LCP-ը փակելու։
- **Համաձայն չեմ** hero-ի կադրը «միջոցառման տպավորություն» լինելու պատճառով անմիջապես փոխելու հետ. սեփականատերը house-01/12-ը հատուկ հաստատել է որպես hero (owner-decisions 2026-11-10). սա իր որոշումն է, ուստի հարց 5-ում առաջարկում եմ այլընտրանք, ոչ թե փոխում։
- **Ճշգրտում** trust strip-ի մասին. աուդիտը գրում է «իրական, ստուգելի թվեր կամ հանել». այսօր ստուգելի թվեր չկան → **հանել**, մինչև հայտնվեն։ Նույնը՝ «Google/Instagram screenshot կարծիքներ»՝ միայն իրական և համաձայնությամբ։
- **Համաձայն եմ** «վերանորոգում/հասարակական առանց նախագծի» խնդրի հետ, և ընտրում եմ տարբեր լուծումներ. վերանորոգումը թողնել (strategy-ի առաջնահերթ սեգմենտն է)՝ «ընթացքի մեջ» օբյեկտով, հասարակականը՝ հանել hero-ից և մենյուից։
- **Լրացում.** աուդիտի առաջարկած Instagram ինտեգրացիան պետք է լինի ստատիկ poster + հղում, ոչ թե embed (արագության պատճառով)։
