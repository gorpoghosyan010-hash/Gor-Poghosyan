## Ամփոփում

Կայքը տեխնիկապես մաքուր է (ստատիկ, արագ JS, Lighthouse Accessibility/SEO/Best Practices = 100), ունի հստակ «մուգ + ոսկեգույն + սերիֆ» ոճ և ինքնատիպ մանրամասներ (գծանկարային splash, scroll-ով կառավարվող տեսանյութ, հաշվիչ)։ Բայց **որպես վաճառող կայք այն թույլ է**.

1. **Վստահության տարրերը գրեթե բացակայում են**՝ չկա հեռախոս/WhatsApp, հասցե/քարտեզ, թիմ, կարծիքներ, երաշխիքներ, լիցենզիաներ, թվեր (տարիներ, օբյեկտներ, մ²)։ Գլխավոր էջի «trust strip»-ը թվերի փոխարեն պարզապես կրկնում է ծառայությունների անունները։
2. **Պորտֆոլիոն փոքր է և անհավասար**՝ 4 նախագիծ (3 լողավազան + 1 տուն), «Վերանորոգում» և «Հասարակական կառույցներ» ուղղությունները չունեն ոչ մի նախագիծ։ Նախագծերի «փաստերը» դատարկ են (տեսակ / կարգավիճակ / փուլ՝ առանց տեղանքի, մակերեսի, ժամկետի)։
3. **Լուրջ սխալ**՝ `/projects` էջում լողավազանների քարտերը տանում են **404**-ի (հարաբերական `href="pool-01"`)։
4. **Կապի ուղին թույլ է**՝ ձևը միայն բացում է այցելուի էլ. փոստի ծրագիրը (`mailto:`), հեռախոսում դա հաճախ ոչինչ չի անում։ Միակ իրական ալիքներն են `info@garon.am` և Instagram։
5. **Պրեմիում տեսքը խանգարում են**՝ ֆոնդային (stock) լուսանկարներ (կասկաներով մարդիկ), գլխավոր hero-ում հարսանեկան զարդարանքով տան գիշերային նկար, շինհրապարակի «հեռախոսային» կադրեր առանց մշակման, 9–10 px մեծատառ հայերեն տեքստեր, ամեն էջ բեռնելիս 3.2 վ splash։

Ընդհանուր գնահատական (10-ից)՝ **տեխնիկա 7, վիզուալ 6, բովանդակություն 3, կոնվերսիա 3, SEO 5**։

### Բաժինների հերթականություն

**Գլխավոր (`/`)**
1. Hero (100svh)՝ նկար `house-01/12.webp` (գիշերային տուն), վերևում eyebrow «GARON CONSTRUCTION · ԵՐԵՎԱՆ» և italic մեջբերում «Գաղափարներ / Կառույցներ / Իրական արդյունք», ներքևում հսկա «G A R O N» սերիֆ բառ, կարճ lead, կոճակներ «Դիտել աշխատանքները» (ոսկե) + «Սկսել նախագիծը»։
2. Trust strip՝ «Լողավազաններ / Տներ / Վերանորոգում» (թվեր չկան)։
3. Փիլիսոփայություն՝ «Շինարարությունը միայն պատեր չէ»։
4. Ծառայություններ՝ 4 տող (թամբնեյլ + համար + վերնագիր + ↗)։
5. Ընտրված աշխատանքներ՝ 3 քարտ (2 լողավազան + տուն)։
6. Հաշվիչի teaser։
7. Statement + «Քննարկել ձեր նախագիծը»։
8. Footer։

**Մեր մասին**՝ hero (stock լուսանկար՝ կասկաներով 3 մարդ) → «Փորձը մեզ համար գործիք է» տեքստ → 4 արժեք (Ճշգրտություն, Որակ, Վստահություն, Արդյունք) → CTA «Տեսեք մեր նախագծերը»։ Թիմ, պատմություն, թվեր, լուսանկարներ չկան։

**Ծառայություններ**՝ hero (stock) → 4 ուղղությունների ցուցակ → CTA։

**Ծառայության էջ (pools/residential/renovation/public-works)**՝ hero (pools/renovation/public-works՝ scroll-ով կառավարվող mp4, residential՝ ձեռքով/scroll-ով սահող նկար) → «Մեր մոտեցումը» (2 սյուն) → Գործընթաց 4 քայլ (մուգ ֆոն) → Հաշվիչ (բացի public-works-ից) → Մեր կառուցած նախագծերը (միայն pools/residential)։ Չկա FAQ, գներ/փաթեթներ (բացի հաշվիչից), երաշխիք, CTA բլոկ էջի վերջում (pools էջը ավարտվում է նախագծերով և անմիջապես footer)։

**Նախագծեր**՝ hero → «Լողավազաններ» ներածություն → 3 քարտ → «Բնակելի» ներածություն → 1 մեծ քարտ → CTA։

**Նախագծի էջ**՝ hero նկար → 3 «փաստ» (Տեսակ / Կարգավիճակ / Փուլ) → ներածություն → պատկերասրահ (masonry ցանց, `<img loading=lazy>`) → CTA։ Չկա «հաջորդ նախագիծ» նավիգացիա, lightbox, տեղանք, մակերես, ժամկետ, հաճախորդի կարծիք։

**Հաշվիչ**՝ hero (stock կասկաներ) → ռեժիմներ (Ամբողջական կառուցում / Միայն մոնոլիտ / Վերանորոգում), մակերես, հարկեր, հարդարման մակարդակ (Ստանդարտ 250 000 ֏/մ², Կոմֆորտ 350 000, Պրեմիում 480 000), հավելյալ checkbox-ներ → մուգ արդյունքի քարտ → (արդյունքը փոխանցվում է կապի ձևին `?estimate=`)։

**Կապ**՝ hero (stock շենք) → ձախ՝ Email + Instagram, աջ՝ մուգ ձևի քարտ (Անուն, Email, Հեռախոս, Նախագծի տեսակ, Հաղորդագրություն)։ Հեռախոս, WhatsApp, Viber, Telegram, հասցե, քարտեզ, աշխատանքային ժամեր՝ չկան։

Ռիթմ՝ բաց ↔ մուգ բաժինների հերթագայություն։ Պալիտրան համահունչ է լոգոյին (սպիտակ/մոխրագույն/ոսկի), բայց **շատ մութ և միապաղաղ**. ջրի/լողավազանի կապույտը, բնական լույսը բացակայում են։

### Տառատեսակներ (`next/font/google`, self-hosted)
- Վերնագրեր՝ **Cormorant Garamond** (լատ./կիր.) + **Noto Serif Armenian** (հայ.), 300–500։
- Տեքստ՝ **Montserrat** (լատ./կիր.) + **Noto Sans Armenian** (հայ.)։
- Խնդիր՝ հայերեն և լատինական սերիֆները տարբեր բնավորություն ունեն (Cormorant-ը նուրբ է, Noto Serif Armenian-ը՝ «գրքային»), արդյունքում հայերեն վերնագրերը պրեմիում չեն թվում։ Eyebrow-ները, նավիգացիան, կոճակները՝ **9–10 px, UPPERCASE, letter-spacing .12–.32em**. հայերեն մեծատառերով նման չափը դժվար ընթեռնելի է։

### Տարածություն և ցանց
- Կողային padding՝ `8vw` (desktop), `7vw` (mobile)։ Բաժինների padding՝ 135 px / 90 px (mobile)։
- Երկու սյունանի «twoCol» (1fr 1fr, gap 9vw) բազային layout-ը կրկնվում է գրեթե բոլոր էջերում → միապաղաղ։
- Header՝ fixed 94 px, scroll-ից հետո blur ֆոն։

### Կոմպոնենտներ
Header + mobile menu (լրիվ էկրան), LanguageSwitcher (dropdown դրոշներով), Splash, Reveal (IntersectionObserver fade-up), ProjectCard (background-image քարտ), ScrollVideo, HeroImage (panorama drag), ServiceCalculator / CostCalculator, ContactForm, ServiceProjects, PageTitle (կլիենտային title)։ `Hero3D.tsx`՝ չօգտագործվող կոդ։

### Պատկերներ
- 37 WebP, 3 MP4 (pool-dive 6.0 MB, public-works 8.5 MB, renovation 3.9 MB)։ `public/services` = 20 MB։
- Իրական լուսանկարներ՝ շինհրապարակի հեռախոսային կադրեր (house-01՝ 12 հատ, pool-01՝ 8), լավ «գործընթացի ապացույց», բայց անմշակ (տարբեր գունային ջերմաստիճան, աղբ, կապույտ բրեզենտ)։
- **Stock**՝ `public/stock/about|calculator|contact|services.webp` (օտարերկրյա մոդելներ կասկաներով)։ About-ի և Calculator-ի hero-ները գրեթե նույն նկարն են։ Պրեմիում բրենդի համար սա վստահություն է իջեցնում։
- Գլխավոր hero-ն և house-01 hero-ն նույն նկարն են (`house-01/12.webp`)՝ գիշեր, պատշգամբին հարսանեկան վարագույրներ, մուտքի մոտ շուն։ Գեղեցիկ է, բայց «միջոցառման» տպավորություն է թողնում, ոչ թե ճարտարապետական։

## Մեծ փոփոխություններ

1. **Ինֆորմացիոն ճարտարապետություն**. Գլխավոր էջը վերակառուցել «ապացույց-կենտրոն»՝ Hero (իրական լավագույն կադր/վիդեո, հստակ առաջարկ + զանգ/WhatsApp) → թվեր → ծառայություններ (մեծ ֆոտո-քարտեր) → ընտրված նախագծեր → գործընթաց (ժամկետներով) → երաշխիքներ → կարծիքներ → FAQ → հաշվիչ → կապ + քարտեզ։
2. **Լեզուներ URL-ով** (`/hy`, `/en`, `/ru` կամ `/`, `/en`, `/ru`) Next.js i18n routing-ով, `hreflang`, առանձին metadata, սերվերային ռենդեր թարգմանված տեքստով։
3. **Պորտֆոլիոյի համակարգ**. նախագծի ձևանմուշ՝ տվյալներ (տեղ, մ², ժամկետ, աշխատանքներ), before/after slider, lightbox, «հաջորդ նախագիծ», ֆիլտր ըստ ուղղության։ Ավելացնել վերանորոգման և հասարակական նախագծեր (կամ ժամանակավորապես հանել այդ ուղղությունները գլխավոր առաջարկից)։
4. **Վստահության բլոկներ**. թիմ (Գոռ Պողոսյան + ինժեներներ՝ լուսանկարներով), կարծիքներ (Google/Instagram screenshot կամ վիդեո), երաշխիքներ (պայմանագիր, ֆիքսված նախահաշիվ, X տարի երաշխիք ջրամեկուսացմանը), լիցենզիա/ՀՎՀՀ, գործընկեր բրենդներ։
5. **Ֆոտո/վիդեո արտադրություն**. պրոֆեսիոնալ նկարահանում (ցերեկային + երեկոյան, դրոն), միասնական գունային մշակում, կարճ loop վիդեոներ hero-ի համար։
6. **Դիզայն-համակարգ**. ավելի բաց պալիտրա (paper/stone + ոսկի + ջրի կապույտ ակցենտ), մեկ հայերեն-լատինական համահունչ տառատեսակային զույգ (օր.՝ Armenian-ը աջակցող display font), 12+ px մանր տեքստ, բազմազան layout բլոկներ (full-bleed ֆոտո, թվերի ցանց, քարտեր, թայմլայն, accordion)։
7. **Կոնվերսիոն ֆանել**. բազմաքայլ «Ստանալ նախահաշիվ» ձև (տեսակ → չափ → բյուջե → կոնտակտ), CRM/Telegram ծանուցում, mobile sticky bar, «Պատվիրել անվճար այց/չափագրում»։
8. **Տեղական SEO**. Google Business Profile, քարտեզ, LocalBusiness JSON-LD՝ հեռախոսով/հասցեով/ժամերով, FAQ schema, ծառայության էջեր ըստ բանալի հարցումների («լողավազանի կառուցում Երևան», «строительство бассейна Ереван»), բլոգ/խորհուրդներ։
9. **Արագություն**. `next/image` responsive `srcset`, hero նկարների preload, AVIF, վիդեոյի adaptive բեռնում, splash-ի հեռացում կամ փոխարինում CSS intro-ով առանց LCP-ը արգելափակելու։
