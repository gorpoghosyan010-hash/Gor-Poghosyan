## Ամփոփում

**Դիրքավորում.** «Շինարարություն առանց անակնկալների — գինը նախապես, երաշխիքը գրավոր, ընթացքը ամեն շաբաթ ձեր հեռախոսում»։

**5 տարբերակիչ.**
1. Ֆիքսված տողային նախահաշիվ
2. Գրավոր երաշխիք (3–5 տարի վերանորոգում, 10 տարի կոնստրուկցիա)
3. Փուլային վճարում, կանխավճար ≤15%
4. Մեկ պատասխանատու + շաբաթական ֆոտո/վիդեո հաշվետվություն + ուշացման տույժ
5. «Թույլտվությունից մինչև բանալի» փաթեթ, սփյուռքի սպասարկում

**Սեգմենտների հերթականություն.** վերանորոգում → տներ և լողավազաններ → փոքր հանրային տենդերներ (9–12-րդ ամսից)։

**Առաջին 3 քայլ.**
1. Ստուգել լիցենզիան hartak.am-ում, կայքում ավելացնել հեռախոս/WhatsApp
2. «Գաղտնի հաճախորդ» ստուգում 5 մրցակցի մոտ
3. Ինքնարժեքի հաշվարկ + պայմանագրի ձևանմուշ իրավաբանի հետ

**Ամփոփում (ռազմավարություն Բ՝ վերանորոգում → տներ/լողավազաններ 4-րդ ամսից).**
- Ներկայիս ենթադրություններով բիզնեսը 24 ամսում շահութաբեր չէ ոչ մի կապիտալի դեպքում. խնդիրը մարժան է ընդդեմ մշտական ծախսերի, ոչ թե կապիտալը։
- Կենսունակ դառնում է, եթե՝ համախառն մարժա +8 կետ, գրասենյակային ծախսեր −20%, բրիգադներ՝ գործավարձով։ Այդ դեպքում 60 մլն ֏-ով փողը վերջանալու հավանականությունը ~10% է, շահույթ 24-րդ ամսում՝ ~50%, ինքնածածկում՝ ~21-րդ ամիս։
- Պետական տենդերները առաջին 24 ամսում վատթարացնում են արդյունքը։
- Հիմնական ռիսկերը՝ տենդեր չհաղթել, կապիտալի պակաս, ֆիքսված գնի թերագնահատում, քիչ հայտեր, լիցենզիայի ուշացում, ԱԱՀ։
