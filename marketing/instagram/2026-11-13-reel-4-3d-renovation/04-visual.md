# R4 «Մոխրագույն բետոնից՝ պատրաստի տուն» — ամբողջությամբ 3D reel

**Ձևաչափ**՝ 1080×1920, 30 fps, 22 վրկ, H.264 + AAC։ Ձայնը՝ միայն 0–6 վրկ (լոգոյի ինտրո), հետո լռություն (երաժշտությունը սեփականատերը ավելացնում է Instagram-ում)։

## Գաղափարը
Հղումը (reference/)՝ վիրուսային AR/VFX reel, որտեղ տեսախցիկը դանդաղ անցնում է չվերանորոգված բնակարանով, և գոտի առ գոտի «տեղում» հայտնվում է պատրաստի ինտերիերը։ Մենք նույնը արել ենք **ամբողջությամբ 3D-ով** (Blender / Cycles), առանց ձեռքի. ամեն բացահայտումից առաջ հատակին և պատերին գծվում են **կապույտ լազերային նշագծման գծեր** (պատերի/կահույքի եզրագծեր), ապա մակերեսի վրա «դիպչելու ալիք» է, և վերջնական ինտերիերը տարածվում է լուսավոր ճակատով ու կայծերով։

| Ժամանակ | Ինչ է կատարվում |
|---|---|
| 0–6 վրկ | L02 լոգոյի ինտրո (անփոփոխ, իր ձայնով) |
| 6–7 | Լոգոն մեծանում ու մարում է, լուսավոր կադրից «բացվում» է չվերանորոգված սենյակը (բետոնե առաստաղ՝ բծերով, ճաքերով, խողովակներով ու լարերով, գազոբլոկ պատեր, սկրիդ, գազոբլոկի ծղոտե դարակ, հին լամպ) |
| 6.5–9 | Լազերային գծեր → ալիք հայելու կետում → լոգարանային գոտի. մուգ քարե պանելներ, կլոր հայելի LED լուսապսակով, ընկույզի փայտից կախովի լվացարանի պահարան, կախովի զուգարան |
| 9–11.5 | Լազերներ → ներկառուցված զգեստապահարան (գրաֆիտ, տաք 3000K LED դարակներ, կախված հագուստ, ծալված իրեր)՝ բարձրանում է ներքևից վերև. փակվում է նաև դռան բացվածքը (թաքնված դուռ) |
| 11–13.5 | Հատակի լազերային ցանց → բաց կաղնե հատակը տարածվում է ամբողջ սենյակով |
| 13.5–16 | Տեսախցիկը թեքվում է աջ → բազմոց (բուկլե), տրավերտին սեղան, գորգ, ձիթենի, փայտե շերտավոր պատ |
| 16–19 | Առաստաղ, ներկառուցված լուսատուներ, LED գիծ, մնացած պատերը և վարագույրը → պատրաստի ինտերիեր, սահուն շարժում |
| 19–22 | Վերջնական կադր (ինչպես R2-ում)՝ թղթի ֆոն, լոգո, «Լողավազաններ · Տներ · Վերանորոգում», garon.am |

Վերևի ձախ անկյունում փոքր GARON լոգո (light տարբերակ, թղթե կիսաթափանց ֆոնի վրա՝ որ կարդացվի և բետոնի, և պանելների վրա)։ Hook տեքստեր, CTA, @handle չկան (owner-preferences.md)։

## Ինչպես է պատրաստված
- **scene.py** — ամբողջ սենյակը պրոցեդուրային է (6×4.5×2.9 մ, պատուհան՝ ձախ պատին, դռան բացվածք). նույն երկրաչափությունը, նույն տեսախցիկը, երկու տեսք՝ `--pass raw` և `--pass fin`։ Ծանր պրոցեդուրային նյութերը (բետոն, գազոբլոկ, սկրիդ, կաղնի, պանելներ, սվաղ) մեկ անգամ «bake» են արվում նկարների մեջ (`render/bake/`, cache), որ ռենդերը ~6 անգամ արագ լինի։ Լույս՝ Nishita երկինք + արև պատուհանից (portal), մեղմ լրացուցիչ լույս, fin-ում՝ 13 ներկառուցված spot (3000K) և LED-եր։ AgX, Medium High Contrast։ fin pass-ը գրում է նաև EXR (գոտու ինդեքս + աշխարհի կոորդինատներ), raw-ը՝ կոորդինատներ (լազերների ծածկման համար)։
- **compose.py** — երկու pass-երի համադրություն. ամեն գոտու դիմակը՝ ըստ object index-ի, ճակատը՝ 3D տարածության մեջ (ալիքը իրականում «վազում» է պատերի ու կահույքի վրայով), փափուկ եզր, bloom, կայծեր, լազերային գծեր՝ 3D-ից պրոյեկցիա տեսախցիկի մատրիցով (թաքնվում են առարկաների հետևում), vignette, թեթև հատիկ, ինտրոյից անցում, անկյունի լոգո, վերջնական կադր։
- **overlays.js** — վերջնական կադրի շերտերը և անկյունի լոգոն (Playwright, նույն տառատեսակներն ու չափերը, ինչ R2-ում)։
- **render.sh** — ամբողջ շղթան։

## Ինչպես վերառենդերել
```bash
python3.11 -m venv <work>/../venv311 && <work>/../venv311/bin/pip install bpy==4.2.0 numpy OpenEXR scipy pillow
bash marketing/instagram/2026-11-13-reel-4-3d-renovation/render.sh <work> 2 16   # <work> = ժամանակավոր թղթապանակ
```
- `bpy==4.2.0` (pip) — Blender 4.2 Python մոդուլ՝ OpenImageDenoise-ով։ Ubuntu-ի `blender` 4.0.2-ը OIDN չունի. `BLENDER=1 render.sh …` տարբերակը աշխատում է նրանով (64 sample, ավելի դանդաղ)։
- 2-րդ արգումենտը՝ քայլ. `2` = ռենդեր 15 կադր/վրկ, հետո `ffmpeg minterpolate` → 30 կադր/վրկ (բյուջեի համար)։ `1` = բոլոր 30 կադրերը (~2 անգամ երկար)։
- Մեկ կադրի փորձարկում՝ `python3.11 scene.py -- --pass fin --out <dir> --single 0,330`, ապա `compose.py <dir> <intro> <ov> <out> --stills --frames 0 --tt 2.0`։
- Նյութը փոխելուց հետո ջնջել համապատասխան bake-ը `render/bake/`-ում։
- Ելք՝ `preview.mp4`, `cover.png`, `contact.jpg`. կադրերի թղթապանակները վերջում ջնջվում են (`KEEP_FRAMES=1` — պահել)։
